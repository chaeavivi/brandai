A. GitHub — 파일 올리고 웹 주소 만들기전원 · 15분

B. Gemini CLI — 터미널에서 AI에게 일 시키기전원 · 15분

  • node -v
  • npm install -g @google/gemini-cli
  • gemini
  • 이 폴더에 있는 파일 목록을 알려줘
  • cd 다운로드

    ※ 다운로드 자리에 파일을 둔 폴더 이름을 넣습니다.

C. Claude Code — 유료 계정 보유자만10분 · 나머지는 강사 화면

  • npm install -g @anthropic-ai/claude-code
  • claude
무료 계정은 실행이 되지 않습니다. 2일차 실습은 Gemini CLI로 동일하게 진행하니 걱정 없이 B까지만 끝내면 됩니다.

D. 막힐 때 — 이 표부터

증상해결
npm install에서 "EACCES" / "권한" 오류터미널을 닫고 시작 메뉴에서 cmd 오른쪽 클릭 → "관리자 권한으로 실행" 후 다시. 그래도 안 되면 손 들기(폴리텍 담당자 권한 필요)
npm install이 멈춰 있음 / "ETIMEDOUT"강의실 망 프록시 문제. 휴대폰 핫스팟으로 잠시 바꿔서 설치만 한 뒤 다시 강의실 와이파이로
"node은(는) 내부 또는 외부 명령이 아닙니다"Node 설치 후 터미널을 새로 열지 않음. 터미널 전부 닫고 다시 열기
gemini 실행 시 로그인 창이 안 뜸터미널에 표시된 주소를 복사해 브라우저에 직접 붙여넣기
GitHub Pages 주소가 404켠 지 1~3분 기다리기. 파일명 대소문자·한글 정확히. Settings → Pages에 초록색 "Your site is live"가 떠야 함
GitHub 이메일 인증 메일이 안 옴스팸함 확인. 그래도 없으면 다른 이메일로 재가입
한글 파일명이 주소에서 깨짐정상. 브라우저가 알아서 변환함. 안 열리면 파일명을 영문으로 바꿔 다시 올리기
