1교시 · 워밍업 · 지식베이스 · 마스터 시트

내 수준을 확인하고, 이틀치 재료를 한 곳에 모은다.
  1. 진단 실습(15분): 담당 사업 하나를 골라 3줄 요약 → 진단 앱 제출
  2. 결과 비교(10분): 같은 과제, 다른 결과 — 프롬프트 차이 확인
  3. 지식베이스 구축(20분): "시작 전 준비" ①~④ 그대로
  4. 마스터 시트 안내(15분): 0_안내 → 같이 걷자가 8개 시트를 지나가는 길 → 6번 시트에 내 사업 한 줄
마스터 입력시트 ⤓마스터시트 설명서.docx

2교시 · 규칙 확정 → 한글에 심기 → HWPX 시연

서식 규칙은 센터에 이미 있다(확인해서 옮긴다). 문체 규칙만 AI로 뽑는다. 둘을 합친 [센터 문서 규칙] 블록이 오후 모든 프롬프트의 맨 위에 붙는다.
  1. 규칙은 이미 있다(8분): 「문서 작성 방법」 + 양식 메모 확인. 계획안 항목 구성(가.~차. vs 1.~7.) 현행 확인
  2. 문체 추출(15분): 같이 걷자 원문 + 프롬프트 P2-1 → 문체 규칙 표. 정답지와 비교, 매일 쓰는 분 쪽 채택
  3. 규칙 블록 완성(10분): P2-2의 [ ] 채우기 → 새 대화에 붙여 "필요성 3문장" 테스트
  4. 서식 변환(3분): 03_서식의 hwp를 한글에서 다른 이름으로 저장 → hwpx와 PDF. hwp(원본)·hwpx(자동화용)·PDF(AI 읽기용) 세 벌
  5. 한글에 심기(12분): 스타일 템플릿(맑은 고딕 11pt 160%, 제목 15pt) · 개요 번호 모양(1.→가.→1)) · 찾아바꾸기(조건식)로 스타일 일괄 적용 · "문자열을 표로"
  6. HWPX 생성 시연(5분): 입력 → JSON → 서식 유지된 hwpx. "완성형은 이렇게까지 된다"
▶ 2교시 프롬프트 복사기 열기계획안 스타일 템플릿.hwp (웹하드 03_서식)같이걷자 계획안 원문.txt (웹하드 02_참고문서)

3교시 · 계획안 계열 (가.~차., 예산 산출근거·검산)

기본정보만 넣으면 센터 서식 계획안 초안이 나온다. 예산은 단가×수량×횟수로 산출근거가 남는다.
  1. 마스터 시트 8번 입력폼에 내 사업 입력 (같이 걷자 예시 참고)
  2. [규칙 블록] + 입력폼 → 계획안 프롬프트 → 초안 생성
  3. 예산표: 산출근거 형식으로 재작성 → 합계 검산 (엑셀 수식)
  4. 한글 템플릿에 붙여넣기 → 찾아바꾸기로 스타일 → 결재 올릴 수 있는 상태인지 P2-3 점검
▶ 3~5교시 프롬프트 복사기 열기사전 생성 결과 팩.md

4교시 · 사업계획서 계열 (PEST·SWOT → 전략체계 → 부서별 운영계획)

평가지침 B.1.1이 보는 세 가지 — 환경분석 근거, 환경분석↔전략체계 연계, 전년도 개선과제 반영 — 가 시트의 "근거" 열과 "개선과제" 열에서 나온다.
  1. 1번 기초자료 → 환경분석 프롬프트 → 2번 PEST 시트 형식 출력 (근거 열 비면 감점)
  2. 3번 SWOT 번호 → 4번 전략체계 "근거" 열에 연결
  3. 5번 KPI 6기준 체크 (구체성·측정가능·원인성·신뢰성·기한성·대표성)
  4. 6번 시트 내 행 → 운영계획 프롬프트 → 서식 표 1세트
▶ 3~5교시 프롬프트 복사기 열기

5교시 · 결과보고서 · 회의록·공문 · 음성 회의록

계획(6번)이 결과(7번)로 이어지고, 개선과제가 다음 해 계획으로 돌아간다.
  1. 7번 시트에 실적 입력 → 달성률·집행률 자동 → 잘된 점·부족한 점·개선과제 작성
  2. 결과보고 프롬프트 → 서식 "추진결과" 표
  3. 회의록·공문: 규칙 블록 + 회의 텍스트 → 회의록 / 공문 문투 교정
  4. 예시 회의 음성 → 클로바노트 → 회의록 자동 생성
▶ 3~5교시 프롬프트 복사기 열기예시 회의 음성회의 대본·정답표

6교시 · 도구 비교 + 검증

같은 프롬프트, 다른 도구. 문서 유형별로 어느 도구가 맞는지 내 기준을 만든다.
  1. 같은 계획안 프롬프트를 Gemini / ChatGPT / Claude에 → 비교표 (정확성·문체·표 처리·속도)
  2. 노트북LM에 "이 계획안이 평가지침 필수항목을 충족하나?" — 근거 기반 검토
  3. 규칙 위반 찾기: 일부러 망가뜨린 계획안 2개 → 사람이 먼저, P2-3으로 대조
  4. AI 결과 검증: 사전 생성 결과 팩에서 사업안내·평가지침과 어긋난 문장 원문 대조
규칙 위반 찾기 · 계획안 A ⤓규칙 위반 찾기 · 계획안 B ⤓

7교시 · 업무도구 기획서 (핵심)

2일차에 만들 도구를 계획안 항목 구조 그대로 기획한다. 필요성·목적·대상은 계획안과 같고, 세부내용은 입력값/출력값, 추진방법은 계산 규칙과 판단 기준.
  1. 도구 후보 고르기: 예산 산출표 · 출장비 계산기 · 상담 건수 집계 · 항목번호 변환기 · 연차 계산기 · 계획안 입력폼
  2. 기획서 작성: 입력값(무엇을 넣나) / 출력값(무엇이 나오나) / 규칙(어떻게 계산·판단하나) — 이 세 칸이 비면 2일차에 못 만듦
  3. 옆 사람과 교환 검토: "입력값만 보고 출력값이 예측되나?"
  4. 기획서 변환기에 옮겨 적기 → 빌드 프롬프트 MD 내려받기 → 옆 사람과 교환 검토
  5. 제출: 내려받은 MD 파일을 제출함 앱 1일차 7교시에 첨부해 제출

1교시 · 복습·점검

  1. 1일차 규칙 블록 + 입력폼으로 계획안 1건 재생성 (손 풀기)
  2. GitHub Pages 링크 · AI 스튜디오 · (보유자) Claude Code 동작 재확인, 미완료자 조치
  3. 기획서 입력값·출력값·규칙 3칸 다시 읽고 구체화 → 요구사항서 확정

2교시 · AI 스튜디오 기초

  1. 예제 파일(예산 계산기)에 항목 하나 추가하기 — 지시 → 확인 → 되돌리기
  2. 자주 쓰는 지시 패턴 5개 정리 (파일 읽기, 수정, 테스트, 되돌리기, 설명 요청)
  3. 오류 메시지를 그대로 붙여넣어 해결하기

3~5교시 · 제작 (입력 → 규칙 → 출력)

  1. 입력 화면: 기획서 입력값을 그대로 폼으로. 필수값 비면 경고
  2. 규칙: 계산식(예산 = 단가×수량×횟수, 합계), 판단(필수항목 누락 검사), 서식(항목번호·공백 들여쓰기)
  3. 출력: 계획안 텍스트 → 복사 / 다운로드. 강사 시연: 같은 JSON으로 HWPX 직접 생성

제공 자료 (교육 자료)

  • 강의 슬라이드
  • 마스터 입력시트 + 설명서
  • 프롬프트 팩 (규칙·계획안·환경분석·운영계획·결과보고·회의록)
  • 센터 문서 규칙 블록 (2교시 산출물)
  • 계획안 스타일 템플릿(HWP) · 서식 반영 가이드
  • 업무도구 기획서 양식
  • 예제 파일 2종 (예산 산출 계산기, 항목번호 변환기)
  • 운영매뉴얼 8단계 로드맵
  • 수업 중 함께 만든 결과물 (그 상태 그대로)

수업 중 결과물은 교육 산출물 · 기관 내부용 · 재배포 및 상업적 이용 금지 · 유지보수 미포함

교육 범위 밖 (별도 협의)

  • 서식 완성형 문서생성기(HWPX 직접 생성 엔진 포함) 구축·납품
  • 운영매뉴얼의 실제 집필·완성
  • 사업계획서 전 항목 대행 작성
  • 제작 도구의 지속적 유지보수

본 과정은 실무자가 문서 자동화 체계와 업무도구를 직접 운용하도록 하는 교육입니다. 위 항목은 필요 시 별도 컨설팅 또는 구축 과제로 협의 가능합니다. (문의: 한국AI평생교육협회)

플러스 자료

강의 중 안내되는 4자리 코드를 넣으면 열립니다. 한 번 열면 이 브라우저에서는 계속 열려 있습니다.

① 증명사진·프로필 사진 만들기 (ChatGPT 이미지·10분)

내 사진 한 장으로 서류용 증명사진과 업무용 프로필 사진을 만든다.
  1. 아래 복사기에서 배경·복장·용도를 고르고 프롬프트 복사
  2. ChatGPT에 본인 사진을 첨부하고 복사한 프롬프트 붙여넣기
  3. 나온 사진에서 얼굴·안경·머리 모양이 어색하지 않은지 확인 후 저장
▶ 증명사진 프롬프트 복사기 열기

※ 사진은 본인 것만 사용합니다. 동료·내담자 사진은 올리지 않습니다.

② 내 업무 자동화 후보 10개 (종이·10분)

2일차에 만들 도구를 고르는 가장 빠른 방법.
  1. 지난 한 달 동안 두 번 이상 반복한 문서 작업을 10개 적기
  2. 각각 옆에 [입력값 / 출력값 / 규칙] 세 칸이 채워지는지 O·X 표시
  3. 세 칸이 모두 O인 것부터 도구 후보 — 7교시 기획서로 넘기기

③ 공문 문투 교정기 (아무 AI·10분)

쓴 문장을 결재 올릴 수 있는 공문 문투로 바꾼다.
아래 문장을 공공기관 공문 문투로 고쳐 줘. 규칙 - 개조식(~함, ~임, ~하고자 함)으로, 한 항목에 한 문장 - 주관적·감정 표현 제거, 추측성 표현은 근거를 묻는 표시를 남길 것 - 숫자·날짜·금액·기관명은 원문 그대로 두고 절대 바꾸지 말 것 - 원문에 없는 내용을 새로 지어내지 말 것 출력 1) 고친 문장만 먼저 2) 그 아래 표로 [원문 / 고친 문장 / 바꾼 이유] [원문]

④ 노트북LM 오디오 개요 (NotebookLM·10분)

기준자료를 두 사람이 대화하는 오디오로 바꿔 출퇴근길에 듣는다.
  1. 노트북LM에서 1교시에 만든 센터 문서작성 기준 노트북 열기
  2. 오른쪽 Studio → 오디오 개요 → 생성 (2~3분 걸립니다)
  3. 들으면서 우리 센터 실제 기준과 다르게 말하는 부분을 메모 — 그 부분이 AI가 틀리기 쉬운 지점

⑤ 엑셀 수식 도우미 (아무 AI·10분)

수식이 기억나지 않을 때 시트 구조만 알려주고 받아 쓴다.
엑셀 수식을 만들어 줘. 시트 구조: (예) A열 날짜, B열 프로그램명, C열 참여인원, D열 예산액, 2행부터 데이터 하고 싶은 것: (예) 프로그램별 참여인원 합계와 1인당 예산 구하기 엑셀 버전: (예) Microsoft 365 / 2016 출력 순서 1) 수식 한 줄 (바로 붙여넣을 수 있게) 2) 각 인수가 내 시트의 어디를 가리키는지 설명 3) 값이 비어 있거나 오류일 때 처리 방법

⑥ 사업 홍보 카드뉴스 3장 (Canva AI·15분)

담당 사업 하나를 인스타그램 카드뉴스 3장으로 만든다.
[정신건강복지센터 사업 홍보 카드뉴스 3장] 사업명: 대상: 핵심 메시지(한 문장): 신청 방법: 문의(전화·주소): 위 내용으로 인스타그램 정사각형(1080×1080) 카드뉴스 3장을 만들어 줘. 1장 - 시선을 끄는 제목 + 대상 2장 - 프로그램 내용 3가지, 각각 아이콘과 함께 3장 - 신청 방법 + 문의처 톤: 공공기관. 차분하고 신뢰감 있는 파랑·초록 계열. 글자는 장당 30자 이내로 최소화하고, 사업명과 문의처는 반드시 넣을 것.

⑦ 같은 카드뉴스를 클로드 디자인으로 (15분)

⑥과 똑같은 내용을 도구만 바꿔 만들어 본다. 어느 쪽이 우리 손에 맞는지 비교하는 것이 목적.
  1. 클로드(claude.ai)에 아래 프롬프트를 붙여넣고, 빈칸을 ⑥에서 쓴 내용 그대로 채우기
  2. 캔버스가 열리면 글자를 눌러 직접 고치기 — 문구·색·크기를 손으로 바꿀 수 있습니다
  3. PNG로 내려받고, ⑥의 Canva 결과와 나란히 놓고 비교하기
[정신건강복지센터 사업 홍보 카드뉴스 3장 — 디자인 캔버스로 만들어 줘] 사업명: 대상: 핵심 메시지(한 문장): 프로그램 내용(3가지): 신청 방법: 문의(전화·주소): 정사각형(1080×1080) 아트보드 3장을 한 캔버스에 나란히 놓아 줘. 1장 - 시선을 끄는 제목 + 대상 2장 - 프로그램 내용 3가지, 각각 단순한 아이콘과 함께 3장 - 신청 방법 + 문의처 디자인 기준 - 공공기관 톤. 파랑·초록 계열에 밝은 배경, 강조색은 한 가지만. - 글꼴은 두 종류까지. 3장이 같은 여백·같은 제목 위치로 한 세트처럼 보이게. - 글자는 장당 30자 이내로 최소화하고, 사업명과 문의처는 반드시 넣을 것. - 사진 없이 글자와 단순한 도형·아이콘만으로. - 글자는 내가 캔버스에서 직접 고칠 수 있게 텍스트로 넣을 것. 지켜야 할 것 - 내가 적은 내용만 쓰고, 참가비·후원기관처럼 안 적은 사실은 지어내지 말 것. - 전화번호·주소·날짜는 한 글자도 바꾸지 말 것.
