2교시 · 규칙 확정 → 한글에 심기 → HWPX 시연

서식 규칙은 센터에 이미 있다(확인해서 옮긴다). 문체 규칙만 AI로 뽑는다. 둘을 합친 [센터 문서 규칙] 블록이 오후 모든 프롬프트의 맨 위에 붙는다.
  1. 규칙은 이미 있다(8분): 「문서 작성 방법」 + 양식 메모 확인. 계획안 항목 구성(가.~차. vs 1.~7.) 현행 확인
  2. 문체 추출(15분): 같이 걷자 원문 + 프롬프트 P2-1 → 문체 규칙 표. 정답지와 비교, 매일 쓰는 분 쪽 채택
  3. 규칙 블록 완성(10분): P2-2의 [ ] 채우기 → 새 대화에 붙여 "필요성 3문장" 테스트
  4. 서식 변환(3분): 03 서식의 hwp를 한글에서 다른 이름으로 저장 → hwpx와 PDF. hwp(원본)·hwpx(자동화용)·PDF(AI 읽기용) 세 벌
  5. 한글에 심기(12분): 스타일 템플릿(맑은 고딕 11pt 160%, 제목 15pt) · 개요 번호 모양(1.→가.→1)) · 찾아바꾸기(조건식)로 스타일 일괄 적용 · "문자열을 표로"
  6. HWPX 생성 시연(5분): 입력 → JSON → 서식 유지된 hwpx. "완성형은 이렇게까지 된다"

3교시 · 계획안 계열 (가.~차., 예산 산출근거·검산)

기본정보만 넣으면 센터 서식 계획안 초안이 나온다. 예산은 단가×수량×횟수로 산출근거가 남는다.
  1. 마스터 시트 8번 입력폼에 내 사업 입력 (같이 걷자 예시 참고)
  2. [규칙 블록] + 입력폼 → 계획안 프롬프트 → 초안 생성
  3. 예산표: 산출근거 형식으로 재작성 → 합계 검산 (엑셀 수식)
  4. 한글 템플릿에 붙여넣기 → 찾아바꾸기로 스타일 → 결재 올릴 수 있는 상태인지 P2-3 점검
▶ 3~5교시 프롬프트 복사기 열기

4교시 · 사업계획서 계열 (PEST·SWOT → 전략체계 → 부서별 운영계획)

평가지침 B.1.1이 보는 세 가지 — 환경분석 근거, 환경분석↔전략체계 연계, 전년도 개선과제 반영 — 가 시트의 "근거" 열과 "개선과제" 열에서 나온다.
  1. 1번 기초자료 → 환경분석 프롬프트 → 2번 PEST 시트 형식 출력 (근거 열 비면 감점)
  2. 3번 SWOT 번호 → 4번 전략체계 "근거" 열에 연결
  3. 5번 KPI 6기준 체크 (구체성·측정가능·원인성·신뢰성·기한성·대표성)
  4. 6번 시트 내 행 → 운영계획 프롬프트 → 서식 표 1세트
▶ 3~5교시 프롬프트 복사기 열기

5교시 · 결과보고서 · 회의록·공문 · 음성 회의록

계획(6번)이 결과(7번)로 이어지고, 개선과제가 다음 해 계획으로 돌아간다.
  1. 7번 시트에 실적 입력 → 달성률·집행률 자동 → 잘된 점·부족한 점·개선과제 작성
  2. 결과보고 프롬프트 → 서식 "추진결과" 표
  3. 회의록·공문: 규칙 블록 + 회의 텍스트 → 회의록 / 공문 문투 교정
  4. 예시 회의 음성 → 클로바노트 → 회의록 자동 생성

같은 프롬프트, 다른 도구. 문서 유형별로 어느 도구가 맞는지 내 기준을 만든다.
  1. 같은 계획안 프롬프트를 Gemini / ChatGPT / Claude에 → 비교표 (정확성·문체·표 처리·속도)

  3. 규칙 위반 찾기: 계획안 A·B를 사람이 먼저 5분 → 검증 프롬프트(P6-1)로 AI 대조 3분 → 정답 공개
  4. AI 결과 검증: 사전 생성 결과 팩에서 사업안내·평가지침과 어긋난 문장 원문 대조

  1. 도구 후보 고르기: 예산 산출표 · 출장비 계산기 · 상담 건수 집계 · 항목번호 변환기 · 연차 계산기 · 계획안 입력폼
