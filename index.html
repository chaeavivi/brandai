Opal 에서 앱 생성하기
## 🏗️ Opal 앱 생성을 위한 마스터 프롬프트

**[App Name]:** Smart Gourmet & Route Planner (스마트 맛집 & 경로 가이드)

**[App Role]:** 사용자가 입력한 특정 시간과 장소를 기반으로 최적의 맛집과 주변 명소를 추천하고, 네이버 맵 연동을 통해 동선 시각화 및 상세 정보를 제공하는 지능형 여행 어시스턴트 앱을 제작해 줘.

**[Core Features & Workflow]:**

1.  **사용자 입력 인터페이스:**
    * `Location`: 사용자가 방문할 중심 지역 (예: 강남역, 제주도 성산읍 등).
    * `Time`: 방문 예정 시간대 (점심, 저녁, 혹은 특정 시간).
    * `Preferences`: 선호하는 음식 종류나 분위기 (선택 사항).

2.  **데이터 분석 및 추천 로직:**
    * 입력된 위치 기준 반경 내에서 평점과 리뷰가 검증된 '진짜 맛집' 1~2곳을 선정해 줘.
    * 식사 전후로 방문하기 좋은 주변 볼거리(카페, 공원, 랜드마크 등)를 코스로 구성해 줘.

3.  **정보 제공 및 외부 링크 연동:**
    * **네이버 맵 연결:** 각 장소 이름에 네이버 지도 검색 결과 링크(`https://map.naver.com/v5/search/{장소명}`)를 하이퍼링크로 연결해 줘.
    * **공식 채널:** 해당 장소의 공식 홈페이지나 인스타그램 예약 링크가 있다면 함께 노출해 줘.

4.  **경로 시각화 (Route Visualization):**
    * 추천된 장소들을 순서대로 나열하고, 전체 경로를 한눈에 볼 수 있도록 '네이버 지도 길찾기' 공유 링크를 생성하여 버튼 형태로 제공해 줘.
    * 결과물은 깔끔한 HTML 표(Table) 또는 카드(Card) UI 형태로 출력해 줘.

**[Output Style]:**
* **Tone:** 친절하고 전문적인 가이드 느낌.
* **Format:** * `Header`: 추천 코스 요약 (예: "성수동에서의 완벽한 오후 코스")
    * `Content`: [장소명] - [특징] - [네이버 지도/홈페이지 링크]
    * `Footer`: 전체 경로 보기 (지도 연동 링크)

### 💡 추가 팁: Opal에서 더 정교하게 만들려면?

생산실적 대시보드 (Opal)
실적 데이터 파일을 업로드받아 한국어 HTML 대시보드를 생성하는 업무형 AI 미니앱을 만들어줘.

앱 목적: 사용자가 구글 스프레드시트 형식의 실적 파일을 업로드하고, 분석 기준을 '전체 데이터' 또는 '특정 날짜' 중 하나로 선택하면, 선택 조건에 맞는 실적 데이터를 분석하여 경영진 보고용 HTML 대시보드로 출력한다.

입력 기능:
1) 파일 업로드
2) 분석 기준 선택
- 전체 데이터 분석
- 특정 날짜 기준 분석
3) 특정 날짜 선택 시 날짜 입력 UI 표시

처리 기능:
1) 업로드 파일의 시트 구조와 헤더를 먼저 파악
2) 날짜 컬럼, 실적 컬럼, 목표 컬럼, 비교 기준 컬럼을 자동 탐지
3) 자동 탐지가 애매하면 후보 컬럼을 제시하고 사용자가 선택할 수 있게 구성
4) 숫자, 날짜, 퍼센트, 통화기호, 공백값 등을 정리하는 전처리 수행
5) 전체 또는 특정 날짜 기준으로 다음 항목 분석
- 총 실적
- 전년 동기 대비 증감
- 전월 동기 대비 증감
- 목표 대비 달성률
- 기간별 추이
- 항목별 비교
- 지역/유형/사업장별 분포
- 이상치 및 특이 패턴 탐지

출력 기능:
1) 결과는 반드시 한국어로만 출력
2) HTML 대시보드 형식으로 출력
3) 디자인은 밝은 회색 배경, 흰색 카드형 박스, 블루 계열 포인트 컬러 중심의 BI 대시보드 스타일
4) 상단에는 KPI 카드
5) 중간에는 게이지 차트, 선형 추이 차트, 막대 차트, 도넛 차트
6) 하단에는 상세 테이블과 심층분석 결과
7) 심층분석 결과에는 반드시 다음 내용 포함
- 주요 성과 요인
- 부진 원인 추정
- 눈에 띄는 추세 변화
- 비교군 대비 해석
- 향후 점검 포인트
- 실무적 개선 제안

출력 규칙:
- 숫자는 가독성 있게 천단위 구분기호 적용
- 퍼센트는 소수점 1자리까지 표시
- 비교 불가 데이터는 '비교 불가'로 표시
- 목표 컬럼이 없으면 목표 관련 카드는 숨기고 대체 설명 제공
- 전년 또는 전월 데이터가 없으면 해당 비교 지표는 생성하지 말고 사유를 표기
- HTML은 단순 텍스트 나열이 아니라 실제 보고용 레이아웃으로 생성
- 마지막 섹션에 심층분석 결과를 문단형으로 자세히 작성
