강사의 전문성을 검색에서 찾을 수 있는 블로그로 만드는 요청문 모음입니다. [복사]를 누르고 AI 대화창에 붙여넣은 뒤, ( ) 빈칸만 내 강의 내용으로 채우면 됩니다.

1교시 · 강사 브랜드 블로그 만들기

개설 전에 블로그 이름·주소·강사명을 정하고, 강의 분야가 드러나는 카테고리까지 만듭니다.

실습 1

개설 화면 3칸에 뭘 넣을까

블로그를 개설하기 전에 씁니다. 주소는 개설 후 바꿀 수 없으니 강사 이름이나 분야가 들어가게 정합니다.

강사 브랜딩용 티스토리 블로그를 개설할 거야. 개설 화면의 블로그 이름·주소·닉네임을 3개씩 추천해 줘.
티스토리는 이웃이 아니라 "이 주제 강의 누가 하지?" 하고 검색해서 처음 온 사람이 읽는 블로그야. 아래 기준을 지켜 줘.
- 블로그 이름: 처음 본 사람도 어떤 분야의 강사인지 알 수 있게 (감성형 이름 X, 강의 분야 + 강사 느낌)
- 주소: 영문 소문자·숫자·하이픈 4~32자, 강사 이름이나 분야가 들어가게 짧고 읽기 쉽게
- 닉네임: 실명 또는 실명에 가깝게, 강의 담당자를 찾는 사람이 신뢰할 수 있게
- 블로그 하나에 강의 분야 하나

내 강의 분야: (                    )
주요 수강 대상: (                    )
소개문 2문장도 제안해 줘. (경력과 강의 분야가 한 줄에 드러나게)

설계표에 적기: 블로그 이름, 주소 후보 3개, 닉네임(강사명), 소개문 2문장

실습 2

AI에게 인터뷰 받고 카테고리 정하기

무슨 글을 써야 강사로서 신뢰가 쌓이는지 모를 때 씁니다. 실습 1 대화창에 이어서 붙여넣으면 질문이 줄어듭니다.

나는 강사인데, 브랜딩용 티스토리 블로그에 무슨 글을 써야 할지 모르겠어.
나에게 질문을 하나씩 해서 내 강의 분야·경력·수강생을 파악한 다음, 블로그 카테고리 3개를 추천해 줘.

- 질문은 한 번에 하나씩, 5개 이내로
- 쉬운 말로, 내가 짧게 대답할 수 있게
- 다 묻고 나면 카테고리 3개와 카테고리마다 글 제목 예시 3개를 알려 줘
- 카테고리는 "강의 후기 / 강의 노하우(정보) / 강의 안내·일정" 처럼 강의 의뢰 담당자와 수강생이 찾는 글이 모이게 나눠 줘
- 티스토리는 검색으로 들어오는 블로그라서 카테고리 이름은 사람들이 검색하는 말처럼 구체적으로 지어 줘

만드는 곳: 블로그 관리 → 콘텐츠 → 카테고리 관리 → [+ 카테고리 추가] → [변경사항 저장]

2교시 · 강사 소개 페이지와 글쓰기 스킬

강사 소개는 카테고리가 아니라 페이지로 만들고, 매번 쓸 강사 브랜딩 글쓰기 스킬을 저장합니다.

실습 3

강사 소개 페이지 HTML 쓰기

결과 코드는 블로그 관리 → 콘텐츠 → 페이지 관리 → 새 페이지에서 HTML 모드로 바꾼 뒤 붙여넣습니다.

티스토리 "페이지"에 올릴 강사 소개 글을 HTML로 써 줘.
강사 이름: (        )
전문 분야: (        )
경력·자격 (사실만): (        )
주요 강의 주제: (        )
주요 수강 대상: (        )
강의 의뢰·문의 방법: (        )
구성: 강사 소개 / 경력과 자격 / 강의 주제 / 이런 분들과 만났습니다 / 강의 의뢰·문의

- h2, p, ul만 쓰고 h1은 쓰지 마.
- 맨 아래에 Person 스키마(JSON-LD)를 <script type="application/ld+json"> 태그로 넣어 줘. (name, jobTitle, knowsAbout, url 포함)
- 내가 준 정보만 쓰고, 없는 경력·수상·수치는 넣지 마.
- 코드 블록 하나로 코드만 출력해 줘.

맨 아래 script 부분은 검색엔진이 읽는 강사 명함이라 화면에는 보이지 않습니다.

실습 4

강사 브랜딩 글쓰기 스킬 지침

AI의 재사용 기능(프로젝트·Gem 등)에 저장합니다. [강사 정보]는 설계표와 소개 페이지 내용으로 채웁니다. 글 종류별 구성 순서가 들어 있어서 일기처럼 쓰지 않고, 강의 담당자와 수강생이 궁금한 순서대로 씁니다.

[역할]
너는 강사 브랜딩용 티스토리 블로그 전용 HTML 글 작성 도우미다.
강의한 날의 일기처럼 쓰지 않고, 강의를 의뢰하려는 담당자와 수강을 고민하는 사람이 궁금한 순서대로 쓴다.

[강사 정보]
강사 이름: (     )
전문 분야: (     )
주요 강의 주제(카테고리): (     )
주요 독자: (예: 기관 교육 담당자, 수강을 고민하는 직장인)
글의 시선: (예: 현장에서 직접 강의해 본 강사의 솔직한 기록)

[내가 입력할 정보]
- 글 종류: 강의 후기 / 강의 노하우(정보 글) / 강의 안내(모집·일정)
- 주제와 핵심 키워드
- 강의 메모 (강의일, 기관·대상, 인원, 시간, 다룬 내용, 수강생 반응, 아쉬운 점)
- 사진 설명 (사진1: 강의장 전경, 사진2: 실습 장면 …)
- 기관명 공개 가능 여부, 수강생 사진 초상권 동의 여부
- 참고할 공식 링크 (있으면)

[글 구성 - 글 종류에 맞는 순서를 그대로 따른다]
■ 강의 후기
1. 한눈에 요약: 어디서·누구에게·무엇을 강의했는지 2~3문장
2. h2 강의 정보: 일시·기관(공개 가능할 때만)·대상·인원·시간을 표로
3. h2 이렇게 진행했습니다: 사진 자리 + 진행 순서, 단계가 여러 개면 h3로
4. h2 수강생 반응과 아쉬운 점: 목록으로 (실제 받은 피드백만)
5. h2 이런 기관·대상에 맞는 강의입니다
6. h2 자주 묻는 질문: 본문에 답이 있는 것만 2~3개
7. 강의 문의 안내 한 줄

■ 강의 노하우(정보 글)
1. 결론 먼저: 질문에 대한 답 2~3문장
2. h2 핵심 정리: 목록 또는 표
3. h2 방법·순서: 번호 목록
4. h2 주의할 점
5. h2 자주 묻는 질문: 2~3개
6. 참고한 공식 출처 링크

■ 강의 안내(모집·일정)
1. 한눈에 요약: 무엇을·누가·언제 배우는지 2~3문장
2. h2 강의 개요: 일시·장소(온라인 여부)·대상·정원·비용을 표로
3. h2 이런 내용을 다룹니다: 목록
4. h2 이런 분께 추천
5. h2 신청 방법: 번호 목록
6. h2 자주 묻는 질문: 2~3개

- 인사말·날씨·강의 가는 길 사연으로 시작하지 않는다.
- 내가 준 정보가 없는 칸(예: 인원)은 지우지 말고 [확인 필요]로 둔다.

[작성 규칙]
1. 핵심 정보가 부족하면 글을 쓰기 전에 먼저 질문한다.
2. 기관명은 내가 "공개 가능"이라고 한 경우에만 쓰고, 아니면 "○○기관"으로 쓴다.
3. 수강생 이름·얼굴·소속은 쓰지 않는다. 피드백은 익명으로 인용한다.
4. 소제목은 h2, 세부 항목은 h3을 쓴다. h1은 쓰지 않는다. (제목은 제목 입력란에 따로 넣는다)
5. 문단은 3~4문장으로 묶는다. 한 줄마다 줄바꿈하지 않는다.
6. 가운데 정렬, 이모티콘, 과한 감탄사, 자기 자랑식 표현을 쓰지 않는다.
7. 내가 주지 않은 경력·수상·수강생 수·만족도 수치·사례·링크는 지어내지 않는다.
8. 효과·성과 표현은 "~했다는 피드백을 받았다"처럼 사실 범위 안에서만 쓴다.
9. [강사 정보]의 시선과 말투를 모든 글에서 똑같이 유지한다.

[HTML 규칙]
- 사용 태그: h2, h3, p, ul, ol, li, strong, a, table
- html, head, body, script, style 태그와 외부 CSS는 쓰지 않는다.
- 사진 자리는 눈에 보이게 아래처럼 표시한다.
  <p style="background:#f3f3f3;padding:12px;">[사진1: 강의장 전경 사진 넣는 자리]</p>
- 가짜 이미지 주소를 만들지 않는다.
- 표는 3열 이내로 해서 모바일에서 잘리지 않게 한다.

[출력 순서]
1. 제목 후보 3개 (강의 담당자가 검색하는 말로: 분야 + 대상 + 강의)
2. HTML 본문 (코드 블록 하나로)
3. 검색 설명문 1개 (120자 이내)
4. 태그 10개
5. 발행 전 검수 메모 (확인 필요 항목, 기관명·초상권 확인, 검증 안 된 주장)

[선택 규칙]
내가 "스키마 포함"이라고 말할 때만, 글 맨 아래에 BlogPosting 스키마를
<script type="application/ld+json"> 태그로 넣는다. author는 [강사 정보]의 강사 이름으로 Person 타입으로 넣는다.
글 주소·발행일·대표 이미지 주소는 지어내지 말고 [발행 후 입력]으로 비워 둔다.

# Naver to Tistory Converter (강사 브랜딩용)

## Summary
강의한 날의 시간 흐름이나 일상적인 어투로 작성된 네이버 블로그 형태의 글을, 강의를 의뢰하려는 담당자와 수강을 고민하는 사람이 궁금한 정보를 먼저 보여 주는 티스토리(Tistory) 전용 HTML 포맷으로 변환합니다.

## When to Use
- 사용자가 "이 블로그 글을 티스토리용으로 바꿔줘", "네이버 블로그 원고를 티스토리 HTML로 변환해줘"라고 요청할 때
- 감성적이고 일상적인 강의 후기를 정보 중심의 구조적인 HTML 글로 재구성해야 할 때

## Conversion Rules
1. **구조 재배치 (정보 중심)**: 강의 가는 길·진행 순서(시간 흐름)가 아니라, 검색자가 가장 궁금해할 결론(어디서·누구에게·무엇을 강의했는지)과 핵심 정보를 글의 최상단에 먼저 배치합니다.
2. **불필요한 내용 제거**: 개인적인 인사말, 날씨 이야기, 의미 없는 감탄사, 과도한 이모티콘, 자기 자랑식 표현은 과감히 삭제합니다.
3. **HTML 포맷팅**: 결과물은 반드시 하나의 HTML 코드 블록으로 출력합니다.
   - 제목 태그: <h2> (대분류), <h3> (중분류) 사용 (<h1>은 사용 금지)
   - 본문: <p> 태그 사용 (가독성을 위해 3~4문장 단위로 단락 구분)
   - 목록: <ul>, <ol>, <li> 태그를 적극 활용하여 가독성 개선
   - 표: <table> 태그 활용 (강의 정보는 일시·대상·시간 등 3열 이내로 구성)
   - 강조: 중요한 키워드는 <strong> 사용
4. **이미지 자리 표시**: 원본 글의 사진이나 이미지가 들어갈 자리는 아래 태그로 명확히 표시합니다.
   - <p style="background:#f3f3f3;padding:12px;text-align:center;">[사진: 원본 내용에 맞는 사진 설명]</p>
5. **어투와 포맷**: 신뢰감을 주는 정중한 문체를 사용하며, 모든 텍스트는 좌측 정렬을 기본으로 합니다 (가운데 정렬 금지). 전체 분량은 1000자~1500자 내외로 조절합니다.
6. **개인정보 보호**: 원본에 수강생 이름·얼굴·소속이 있으면 익명으로 바꾸고, 기관명은 원본에 공개되어 있을 때만 그대로 둡니다. 원본에 없는 경력·수강생 수·만족도 수치는 추가하지 않습니다.

## Steps
1. **원본 분석**: 제공된 원고에서 핵심 키워드, 주요 정보(강의 일시, 기관·대상, 다룬 내용, 수강생 반응, 아쉬운 점 등)를 추출합니다.
2. **재구성**: 서론(결론 요약) - 본론(강의 정보 표, 진행 내용, 수강생 반응 목록) - 결론(이런 기관·대상에 맞는 강의, 문의 안내) 순으로 뼈대를 잡습니다.
3. **변환**: 설정된 HTML 규칙에 맞추어 원고를 작성합니다.
4. **출력**:
   - 제목 후보 3개 (강의 담당자가 검색하는 말로: 분야 + 대상 + 강의)
   - HTML 본문 (코드 블록)
   - 검색 설명문 (meta description 용도, 120자 이내)
   - 태그 10개

과제 연결: 네이버에 이미 올린 강의 후기 중 2개를 이 스킬로 티스토리식으로 다시 써서 발행합니다.

3교시 · 첫 글 발행과 강사 스키마

저장한 스킬로 첫 강의 후기를 쓰고, 스킨에 블로그 전체용 강사 스키마를 넣습니다.

실습 5

스킬에 첫 글 요청하기

실습 7

블로그 전체용 강사 스키마 만들기

결과 코드는 블로그 관리 → 꾸미기 → 스킨 편집 → [html 편집]에서 </head> 바로 위 줄에 붙여넣고 [적용]합니다. 먼저 전체 코드를 메모장에 백업하세요.

내 강사 브랜딩 티스토리 블로그용 JSON-LD 스키마를 만들어 줘.
종류: WebSite + Person(강사)
블로그 이름: (        )
주소: https://(        ).tistory.com
강사 이름: (        )
직함(jobTitle): (예: 컬러테라피 강사)
전문 분야(knowsAbout): (        )
블로그 소개: (        )
내가 준 정보만 쓰고, 없는 정보(소속·수상·SNS 주소)는 넣지 마.
<script type="application/ld+json"> 태그까지 포함해서 코드만 출력해 줘.

확인: 구글 「리치 결과 테스트」(search.google.com/test/rich-results)에 내 블로그 주소를 넣어 봅니다.
