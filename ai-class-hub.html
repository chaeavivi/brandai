SETUP

설치·연결 가이드

수업 중에 막히면 이 순서대로 다시 확인.

리뷰언즈 엔서포터 설치와 블로그 문체 학습1부

설치

  1. 크롬에서 아래 버튼으로 Chrome 웹 스토어의 리뷰언즈 엔서포터 페이지 열기
  2. Chrome에 추가 클릭 → 팝업에서 확장 프로그램 추가
  3. 주소창 옆 퍼즐 아이콘에서 엔서포터 고정
  4. 버전 확인: 주소창에 chrome://extensions 입력 → 엔서포터 카드에서 0.7.3인지 확인
Chrome 웹 스토어에서 설치

블로그 글로 내 문체 학습시키기

  1. 내 블로그에서 평소 말투가 잘 드러난 글 3~5편 고르기
  2. 글을 열고 엔서포터의 MS워드 내보내기로 Word 파일 저장
  3. Claude 프로젝트에 Word 파일 업로드
  4. Claude에게 요청: 업로드한 블로그 글을 읽고 내 말투·문장 길이·자주 쓰는 표현·피하는 표현을 문체 가이드로 정리해줘
  5. 받은 문체 가이드를 프로젝트 지침에 붙여 두기 (3부 스킬에도 그대로 사용)

파일 이름은 영문으로 저장하기. 한글 파일명은 업로드·다운로드 오류가 자주 남.

Claude × Canva 연결2부
  1. Claude 설정의 커넥터 메뉴에서 Canva 찾기
  2. 연결 클릭 → Canva 계정으로 로그인 → 권한 허용
  3. 새 대화에서 Canva 연결됐는지 확인해줘로 점검
  4. 교안 만들 땐 참고할 Canva 템플릿 링크를 함께 주기

AI가 임의로 뽑은 디자인보다 내가 고른 템플릿 스타일을 따르게 하는 쪽이 결과가 훨씬 나음. 내가 손으로 고친 디자인은 다시 AI에게 맡기지 않기.

Claude × Gmail 연결확장 실습
  1. Claude 설정의 커넥터 메뉴에서 Gmail 찾기
  2. 연결 클릭 → 출강 문의를 받는 Google 계정 선택 → 권한 허용
  3. 요청 예시: 최근 출강 문의 메일을 찾아서 기관·일시·인원·예산을 정리해줘
  4. 이어서: 이 내용으로 강의계획서 초안과 답장 초안을 만들어줘

답장은 초안까지만. 기관명·담당자명·날짜를 직접 확인한 뒤 발송.
