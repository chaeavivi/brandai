[어제 만든 자료가 없을 때 쓰는 예시 · 2일차 매크로 샘플 기준 · 가상 데이터]

■ 1. 매크로 설명 메모
- 매크로 이름: 매크로 샘플 (Day2_P4_Macro_Sample.xlsm)
- 한 문장 요약: 신청명단의 사람이 조합원인지 찾고, 조합원 여부에 따라 자부담 금액을 계산한다.
- 버튼 ① 매칭키 만들기: 이름 띄어쓰기를 지우고, 생년월일 6자리와 전화번호 숫자만 남겨 "이름|생년|전화" 열쇠를 G열에 만든다. 조합원명단에 같은 열쇠가 있으면 H열에 O, 없으면 X. 전화번호가 비어 있으면 노란 줄(사람이 확인).
- 버튼 ② 자부담 계산: 상품코드 시트에서 농협보조·농가부담 단가를 찾아 I열에 자부담 금액을 적는다. 조합원은 포당 농가부담, 비조합원은 농가부담+농협보조. 합계는 K2 칸.
- 버튼 ③ 결과 지우기: G·H·I열과 K2를 비운다. 다시 할 때는 ③ → ① → ② 순서.
- 입력 시트와 열: [신청명단] A 번호 / B 성명 / C 생년월일 / D 전화번호 / E 상품명 / F 수량(포), [조합원명단] A 성명 / B 생년월일 / C 전화번호, [상품코드] A 상품명 / B 농협보조 / C 농가부담
- 결과: G 매칭키 / H 조합원여부 / I 자부담금액 / K2 합계(642,440원) / [실행기록] 시트에 실행할 때마다 한 줄

■ 2. 점검 체크리스트 (오류가 났을 때 순서대로)
1. 위쪽에 빨간 줄 "보안 위험"이 있나? → 파일 닫고 우클릭 → 속성 → 차단 해제
2. 노란 줄 [콘텐츠 사용]을 눌렀나? → 안 눌렀으면 누르기
3. 시트 이름이 바뀌지 않았나? (신청명단 · 조합원명단 · 상품코드) → 원래 이름으로
4. 상품명 띄어쓰기가 [상품코드]와 같은가? (예: "푸른 들" ≠ "푸른들") → 원본 고치기
5. 전화번호·생년월일이 비어 있는 줄이 있나? → 노란 줄 확인
6. 결과가 이상하면 ③ 결과 지우기 → ① → ② 다시
7. 저장은 반드시 .xlsm (xlsx로 저장하면 매크로가 사라짐)
8. 그래도 안 되면 오류 창을 캡처해서 AI에게 묻기 (실제 조합원 이름은 가리기)

■ 3. 자주 나는 오류
- "프로젝트를 볼 수 없습니다" / 매크로 버튼이 안 눌림 → 파일 차단(1번)
- 1004 오류 → 시트 보호·통합 문서 보호가 걸려 있음 → 검토 탭에서 확인
- #N/A 또는 자부담이 0 → 상품명 글자가 다름(4번)
