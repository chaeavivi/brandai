# 3~5교시 프롬프트 팩

## 공통 규칙 (모든 프롬프트에 적용)

- 맨 위 `[센터 문서 규칙]` 자리에 2교시에서 만든 **[센터 문서 규칙] 블록**을 붙인다.
- 없는 사실은 만들지 않는다. 모르는 값은 `[확인 필요]`.
- 한 번에 표 하나·문서 하나만 요청한다.

| 교시 | 프롬프트 | 넣는 것 | 나오는 것 |
|---|---|---|---|
| 3 | P3-1 계획안 초안 → P3-2 예산표 | 시트 8번 입력폼 | 한글 계획안 |
| 4 | P4-1 환경분석 → P4-2 KPI | 시트 1·4번 | 시트 2·5번, 사업계획서 |
| 5 | P5-1 결과보고 → P5-2 회의록 | 시트 7번, 회의 텍스트 | 결과보고서, 회의록 |

## P3-1. 계획안 초안 — 3교시

```
[센터 문서 규칙]

[역할] 원주시정신건강복지센터 사업 담당자. 아래 [입력정보]로 내부 계획안(붙임문서)을 작성한다.

[작성 규칙]
- 항목 순서: 1. 필요성 → 2. 목적 → 3. 사업 내용 → 4. 예산 → 5. 진행 및 역할분담 → 6. 평가 → 7. 기대효과 → 붙임
- 번호와 들여쓰기는 텍스트로 직접 쓴다: "1." 0칸, "  가." 2칸, "    1)" 4칸, "      가)" 6칸
- 필요성은 3문장: ① 입력된 통계·근거 → ② 지역사회 과제로 해석 → ③ 따라서 본 사업. 근거가 없으면 [근거 통계 확인 필요]
- 대상·일시·장소·접수는 "가. 대   상 : " 형식(라벨 글자 사이 띄움)
- 예산은 표: 구분 | 산출내역(단가 × 수량 × 횟수) | 단위(원). 합계를 계산해 "총 계" 행에 쓴다
- 기대효과는 가.나.다. 3개 이내, 명사형 종결
- 마지막 줄: "붙임  1. ○○ 1부.  2. ○○ 1부.  끝."

[입력정보]
사업명:
추진배경(근거 통계·출처):
목적:
대상·인원:
일시:
장소:
프로그램·세부내용:
협조기관:
예산(재원, 항목, 단가, 수량, 횟수):
평가 방법:
기대효과:
붙임:
```

## P3-2. 예산표만 다시

```
아래 예산 항목을 "구분 | 항목 | 산출근거 | 금액(원)" 표로 다시 쓰세요.
산출근거는 "단가 × 수량 × 횟수", 금액은 1,000,000 형식, 마지막 행 "총 계".
표 아래에 "검산: a + b + c = 합계" 한 줄.

[예산 항목]
(붙여넣기)
```

## P4-1. 환경분석 — 4교시

```
[센터 문서 규칙]

[역할] 사업계획서 "환경분석" 작성 담당자.
[할 일] 아래 [기초자료]만 근거로 PEST 표를 만들고, 그 아래 SWOT 4칸으로 정리한다.

PEST 표(열 5개): 구분(P/E/S/T) | 번호(P1, E1…) | Key Point(사실 한 문장) | 근거자료(출처명) | 시사점("센터는 ~해야 한다")
- 기초자료에 있는 사실만. 근거 없는 행은 쓰지 않는다
- 구분별 2개 이상, 총 8~12행

SWOT: S/W/O/T 각 2~3개, 항목 뒤에 근거 번호(예: P1, S2)를 괄호로 붙인다.
마지막에 "전년도 개선과제 반영" 1줄.

[기초자료]
(시트 1번의 지역통계·정책·전년도 개선과제 행을 복사해 붙여넣기)
```

## P4-2. KPI 설계 + 6기준 체크

```
[센터 문서 규칙]

아래 [전략과제]마다 KPI 1개를 설계하세요.
형식: 전략과제 | 성과지표명 | 측정산식 | 목표치(숫자) | 담당팀 | 6기준 체크
6기준: 구체성 · 측정가능성 · 원인성 · 신뢰성 · 기한성 · 대표성 — 각 O/X와 한 줄 이유
- 계량·결과지표 우선. 만족도만으로 끝내지 않는다
- X가 하나라도 있으면 대안 지표를 하나 더 제시

[전략과제]
(시트 4번에서 복사)
```

## P5-1. 결과보고 — 5교시

```
[센터 문서 규칙]

아래 [추진결과 정보]로 결과보고서 "추진결과"를 작성하세요.

출력:
① 성과 표: 성과지표명 | 목표 | 실적 | 달성률(%)
② 예산 표: 계획 | 집행 | 집행률(%) | 저조 사유
③ 주요 내용: 실행 내용 + 실적, 5줄 이내
④ 성과 분석 표: 잘된 점·부족한 점 | 개선과제 | 다음 연도 반영 계획

- 달성률·집행률은 주어진 숫자로만 계산(소수 첫째 자리)
- 개선과제는 "~을 ~로 조정" 형태의 행동 문장

[추진결과 정보]
(시트 7번 한 행)
```

## P5-2. 회의록

```
[센터 문서 규칙]

아래 [회의 내용]을 회의록으로 정리하세요.
형식: 회의명 / 일시 / 장소 / 참석자(직위만, 이름은 쓰지 않는다) / 안건 / 논의 내용(안건별 가.나.다.) / 결정사항(번호 · 담당 · 기한) / 미결 / 향후 일정
- 발언을 옮기지 말고 결정과 근거 중심으로
- 결정사항은 "무엇을 · 누가 · 언제까지"가 다 있어야 한다
- 결정 안 된 것은 "미결"에 둔다

[회의 내용]
(클로바노트 변환 텍스트)
```
